# 🌐 Portfolio - Elena Kervennic

Bienvenue sur mon portfolio personnel ! Ce projet est un site web statique présentant mes compétences, mes projets et mes informations de contact.

---

## 📋 Description

Ce portfolio a été conçu pour présenter mon travail en tant que développeuse web. Il est construit avec des technologies web simples et modernes, sans framework, pour rester léger et rapide.

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure de la page
- **CSS3** — Design et mise en page (Flexbox, Grid, animations)
- **JavaScript** — Interactions dynamiques

---

## 📁 Structure du projet

```
Portefolio/
├── index.html       # Page principale du portfolio
└── README.md        # Ce fichier
```

## 💻 Lancer le projet en local

1. Clone le dépôt :
   ```bash
   git clone https://github.com/ekervennic/Portefolio.git
   ```
2. Ouvre le fichier `index.html` dans ton navigateur.

C'est tout ! Pas besoin d'installer quoi que ce soit.
